# JACK · honey 的生日小屋

纯静态生日网页：探索 3D 小屋、拆礼物、选择预设祝福、吹蜡烛和观看烟花。

## 本地预览

需要 Node.js 18 或更新版本，无需安装依赖：

```powershell
cd D:\gptcode\jack-birthday
node server.mjs
```

访问 http://127.0.0.1:4173 。也可用 start-preview.ps1 在 4174 端口预览。

## 部署

将 dist 目录中的全部文件上传到任意支持静态文件的托管服务即可，发布根目录设为 dist，无需构建命令、Node.js 服务或数据库。样式和脚本使用相对路径，可放在域名根目录或子目录。请通过 HTTP/HTTPS 访问，避免直接双击 HTML 导致模块加载受限。

祝福弹窗提供六个选项：生日快乐、每天都有大鸡腿吃、健康平安、每天开开心心、一直做自己喜欢的事、心愿都能慢慢实现。无需昵称和文字输入；选择仅用于当前页面的生日流程，刷新后重新开始。没有共享祝福墙、访客留言接口或数据库读写。已有 data 目录中的历史数据库未删除，不属于部署内容。

## 保留的互动

- WebGL 3D 小屋、拖动视角和重置，Three.js 固定版本随 dist/vendor 附带。
- 电吉他、小动物和四个生日彩蛋；参照用户图片制作的大头棕色小猴子会沿空地散步、摆腿、摇尾巴和眨眼，点击可挥手。减少动态效果模式下停留原地。
- 小屋相机取景拉近，桌面与手机的显示区域放大；场景角落文字改为「闪闪发光」。
- 礼物打开后出现草莓蛋糕，再点蛋糕弹出祝福选择；也可通过首页「选一句祝福」进入。
- 选好祝福后长按一秒吹蜡烛，或主动授权麦克风检测吹气；结尾显示所选祝福与烟花。
- 麦克风仅在本机分析音量，不录音、不上传；关闭窗口、完成或超时即释放。远程使用需 HTTPS；长按按钮无需麦克风。
- 背景音乐来自用户提供的视频，原样提取 AAC 音轨为 dist/audio/birthday-v2.m4a（约 4 分 02 秒、1.52 MB），无需外部音乐服务。页面打开时尝试有声循环播放；浏览器若拦截自动播放，首次点击页面或按回车/空格时重试。右上角可随时暂停或恢复，手动暂停后不会被后续点击重新开启。切到后台暂停，回来时按原播放意愿恢复。
- 移动端布局、键盘操作、原生对话框焦点约束和减少动态效果偏好支持。
